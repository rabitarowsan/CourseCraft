<p>
A modern and responsive <b>Course Management System</b> developed using 
<b>Laravel</b>, <b>PHP</b>, and <b>JavaScript</b>.
This project allows administrators or instructors to create and manage online courses with media support, pricing options, and detailed course information.
</p>

<hr>

<h2>🚀 Features</h2>

<ul>
  <li>✅ Create and manage courses</li>
  <li>✅ Upload course thumbnails / feature images</li>
  <li>✅ Add feature video links (YouTube / Google Drive)</li>
  <li>✅ Rich text editor for course descriptions</li>
  <li>✅ Course category management</li>
  <li>✅ Course level selection</li>
  <li>✅ Pricing and discount system</li>
  <li>✅ Responsive admin dashboard</li>
  <li>✅ Form validation</li>
  <li>✅ File upload handling</li>
  <li>✅ Clean and user-friendly UI</li>
</ul>
